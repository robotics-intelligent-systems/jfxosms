# Open Source Microfactory Simulation

Eclipse Tractus-X is a collaborative, open-source project aimed at driving the digital transformation of the automotive industry and beyond. FactorySimPy is a light-weight Python library for modeling and discrete-event simulation of manufacturing systems. IndustryFusion is the open source IIoT connectivity solution for smart products and smart factories. The IndustryFusion Process Data Twin Architecture is designed to address the challenges of digital transformation in the manufacturing sector. OpenFactory is a deployment and coordination platform for the physical world. The Open Factory Twin (OFacT) project aims to provide a digital twin for production and logistics environments. Open Industry Project is a free and open-source warehouse/manufacturing development framework. Factory I/O is a 3D factory simulation for learning automation technologies. IMES is an open source manufacturing execution system application designed for Small-Midsize JobShop Manufacturer. Factory floor simulator written in Python using simpy. open-microfactory is an open-source robotic assembly cell designed to perform dexterous manipulation tasks. PackML MQTT Simulator is a virtual line that interfaces using PackML implemented over MQTT. PLC automation simulation using OpenPLC and FactoryIO. Libre is an open source manufacturing execution and performance monitoring. Manufacturing Efficiency & Maintenance Management Platform. Factory Management System for Space Dimensions Company. The system is designed to manage various aspects of the factory, including its details, products, employees, and customers. Simulate manufacturing or service processes with Discrete Event Simulation to identify bottlenecks and remove them through scenario-planning.
